# 数値計算の可観測性

## 原則

Quanteliaは計算の意味を明示し、結果と数値的な挙動を検証可能にします。実行時間の計測やコンパイラ内部の観測機能を再実装しません。

## 観測したい情報

- 要素型、入力・出力shape、要素数
- 演算・Reductionの順序と丸め
- 許容誤差、NaN・Infinity・符号付きゼロなどの比較規則
- 不正shape、範囲外、整数オーバーフローなどの失敗条件
- CeruneのIR・MIR・SSA・VM・生成コードと対応する再現可能な入力

## 観測と計算を分ける

観測の有効・無効が計算の意味を変えてはいけません。読み取り専用の観測情報と、計算内容を制御・変更するAPIは分けます。

処理時間は入力と実行環境で変動するため、数値演算の決定的な結果とは分離して記録します。計測対象・準備処理・繰り返し・使用した実行経路を明示します。

## 最初の検証

`examples/basic_tensor.ceru`はTensorの形・rank・numelを表示する初期例です。shape不一致を検出する実装や浮動小数点の演算観測は、まだ実装されていません。

今後、既知の期待値と異常入力を追加し、可能なCeruneの経路間で出力と停止を比較します。
